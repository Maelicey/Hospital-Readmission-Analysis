# Hospital-Readmission-Analysis
SQL and Tableau project analyzing factors associated with hospital readmissions.

# Project Overview

This project analyzes hospital patient data to identify factors associated with patient readmissions.
The analysis was performed using SQL for data exploration and Tableau for dashboard development.

# Tools Used
- SQL
- Tableau Desktop
- GitHub

# Dataset

The dataset contains 8,000 hospital patient records, including:
- Age
- Gender
- Insurance Type
- Comorbidities Count
- Medications Count
- Previous Readmissions
- Length of Stay
- Readmission Status
  
# Key Findings

- Readmitted patients were older than non-readmitted patients.
- Readmitted patients had more comorbidities.
- Readmitted patients took more medications.
- Previous readmissions were associated with future readmissions.
- Patients with longer hospital stays were more likely to be readmitted.

# Recommendation

Hospitals should provide stronger follow-up care and home-care support for high-risk patients to reduce readmission rates.
